# Blues For Alice 分析

`Blues For Alice` を、**Bird Bluesのii-V連鎖**を学ぶための基準曲として整理する。  
本ページの進行は `JazzStandards/JazzStandards/Blues For Alice.json` の記述を基準にしている。

---

## 基本情報

| 項目 | 内容 |
|------|------|
| 曲名 | Blues For Alice |
| Composer | Charlie Parker |
| Key | F |
| Rhythm | Medium Up Swing |
| Time Signature | 4/4 |
| Form | 12小節（Bird Blues） |

メモ:
- 2小節目 `Em7b5,A7b9` から終盤まで、連鎖的な接続が続く。
- 3小節目の `G7(Db7)` 注記は、ドミナント差し替えの運用幅を示す。

---

## フォームとキーセンター

| 区間 | キーセンター | 役割 |
|------|--------------|------|
| 1-4 | F中心 | Bird Blues冒頭の連結導入 |
| 5-8 | Bb→F周辺 | サブドミナント経由で下降連結 |
| 9-12 | Gm7-C7中心 | ターンアラウンドで次周接続 |

要点:
- 通常ブルースよりコード密度が高く、**2拍または1小節単位で着地管理**が必要。
- 12キー練習では、まず「3rd着地だけで1コーラス通す」ことを優先。

### 区間別ラベル（目安）

| 区間 | 主な進行 | 進行ラベル | 推奨スケール（第一候補） |
|------|----------|------------|--------------------------|
| 1-4 | `Fmaj7 -> Em7b5,A7b9 -> Dm7,G7 -> Cm7,F7` | Bird Blues導入連鎖 | F Ion-Lyd / E Loc / A Alt / D Dor |
| 5-8 | `Bb7 -> Bbm7,Eb7 -> Am7,D7 -> Abm7,Db7` | 下降ii-V連鎖 | Mix + Dorの連結 |
| 9-12 | `Gm7 -> C7 -> Am7,Dm7 -> Gm7,C7` | ターンアラウンド終端 | G Dor / C Mix |

## セクション別コード機能

- 1-4: Imaj7から即座に連鎖へ入る導入
- 5-8: サブドミナント経由で半音/全音下降しながら接続
- 9-12: ii-V中心で次周へ戻す

---

## ガイドトーン接続（3rd/7th）

| 進行 | 着地候補（例） |
|------|----------------|
| Em7b5 -> A7b9 -> Dm7 | `G -> C# -> F` |
| Bbm7 -> Eb7 -> Am7 -> D7 | `Db -> G -> C -> F#` |
| Abm7 -> Db7 -> Gm7 | `Cb(B) -> F -> Bb` |
| Gm7 -> C7 -> Fmaj7 | `Bb -> E -> A` |

実践ルール:
1. 1小節目を基準点にして各小節1拍目を固定
2. 5-8小節は2拍ずつで読む練習を追加
3. 3小節目 `G7(Db7)` は最初はG7固定、次にSubVを導入

---

## 即興設計（スケール / テンション）

| コード | 第一候補 | テンション運用 |
|-------|----------|----------------|
| Fmaj7 | Ionian / Lydian | 9,13,#11 |
| m7 / m7b5 | Dorian / Locrian | 9,11中心 |
| 7 / 7b9 | Mixolydian / Altered | b9,#9,b13を短く |
| `G7(Db7)` | Mix + SubV-Lydb7 | 置換の音色比較 |

優先順位:
1. まずコードトーンのみで通す
2. 次にV7のみテンション追加
3. 最後にSubVやオルタード差し替えを行う

---

## コンピング設計

### 1. 初級（シェル）

- 小節頭の機能だけ明確に打つ
- 連鎖区間は音数を増やしすぎない

### 2. 中級（ルートレス）

- `m7-7` ペアを同型で順送り
- 9-12でターンアラウンドを強調

### 3. 実戦運用

- ソロ初回は薄く、後半で密度を上げる
- ベースと衝突しない音域を維持

## 15分練習メニュー

| 時間 | 内容 |
|------|------|
| 3分 | 1-4小節を反復 |
| 3分 | 5-8小節の下降連鎖を反復 |
| 3分 | 9-12小節ターンアラウンドを反復 |
| 3分 | 12小節通し（1拍目着地固定） |
| 3分 | 2コーラス目でV7差し替え比較 |

到達基準:
- ✅ 連鎖区間でフォームを見失わない
- ⭐ 2拍単位でも着地管理できる
- 🔥 12キーでBird Blues語彙を再利用できる
