# Billie's Bounce 分析

`Billie's Bounce` を、**ジャズブルースの基本運用**と**ターンアラウンド処理**の基準曲として整理する。  
本ページの進行は `JazzStandards/JazzStandards/Billie's Bounce.json` の記述を基準にしている。

---

## 基本情報

| 項目 | 内容 |
|------|------|
| 曲名 | Billie's Bounce |
| Composer | Charlie Parker |
| Key | F |
| Rhythm | Medium Up Swing |
| Time Signature | 4/4 |
| Form | 12小節ブルース（JSON記法: 1セクション） |

メモ:
- `Now's The Time` と同型進行として扱える。
- 6小節目の `B°7`、8小節目の `Am7,D7` がジャズブルースらしさの核。

---

## フォームとキーセンター

| 区間 | キーセンター | 役割 |
|------|--------------|------|
| 1-4 | F7中心 | I7土台 + 4小節目でIVへ向かうii-V |
| 5-8 | Bb7→F7 | IV提示 + 減七経過 + VI7接続 |
| 9-12 | Gm7-C7中心 | ii-Vターンアラウンドで次周接続 |

要点:
- ブルースはシンプルに見えて、**経過和音の運用で難易度が上がる**。
- 12キー練習では「ブルース語彙を全キーで弾く」前に「9-12小節の接続」を固定する。

### 区間別ラベル（目安）

| 区間 | 主な進行 | 進行ラベル | 推奨スケール（第一候補） |
|------|----------|------------|--------------------------|
| 1-4 | `F7 -> Bb7 -> F7 -> Cm7,F7` | I7土台 + IV接続準備 | F Mix-Blues / Bb Mix / C Dor |
| 5-8 | `Bb7 -> B07 -> F7 -> Am7,D7` | IV提示 + 減七経過 + VI7 | Bb Mix / B Dim / F Mix / A Dor |
| 9-12 | `Gm7 -> C7 -> F7,D7 -> Gm7,C7` | ii-Vターンアラウンド | G Dor / C Mix / F Mix / D Mix |

---

## セクション別コード機能

- 1-4: I7中心、4小節目で次のIVへ向かう接続を作る
- 5-8: IVで開いてから `B°7` で緊張を作り、I7へ回帰
- 9-12: `ii-V` を2回配置して次周に接続

---

## ガイドトーン接続（3rd/7th）

| 進行 | 着地候補（例） |
|------|----------------|
| F7 -> Bb7 -> F7 | `A -> D -> A`（3rd反復） |
| Bb7 -> B07 -> F7 | `D -> D -> A`（共通音経由） |
| Gm7 -> C7 -> F7 | `Bb -> E -> A`（3rd連結） |
| F7 -> D7 -> Gm7 | `A -> F# -> Bb`（終端接続） |

実践ルール:
1. 9-12小節は毎回同じ着地で固定
2. 6小節目 `B°7` は長く伸ばさず経過音扱い
3. 1コーラスで使うブルース語彙を2種類に限定

---

## 即興設計（スケール / テンション）

| コード | 第一候補 | テンション運用 |
|-------|----------|----------------|
| F7 / Bb7 / C7 / D7 | Mixolydian + Blues混在 | 9,13（必要時b9/#9） |
| Cm7 / Am7 / Gm7 | Dorian | 9,11 |
| B07 | Half-Whole Dim | 経過的に短く |

優先順位:
1. F7上でブルース語彙を固定
2. 9-12のii-Vで拍頭着地を維持
3. 6小節目と8小節目の差し色を後から追加

---

## コンピング設計

### 1. 初級（シェル）

- I7/IV7/V7の3機能を明確に分離
- 9-12で密度をやや上げる

### 2. 中級（ルートレス）

- `Cm7-F7` と `Gm7-C7` を同型で処理
- `F7-D7` はトップノート半音接続を作る

### 3. スイング運用

- 2拍4拍を支点に短いヒット中心
- ソロが詰まる場面では2フィールへ下げる

## 15分練習メニュー

| 時間 | 内容 |
|------|------|
| 3分 | 1-4小節のI7土台を反復 |
| 3分 | 5-8小節（`B07`,`Am7,D7`）を反復 |
| 3分 | 9-12小節ターンアラウンドを反復 |
| 3分 | 12小節通し（拍頭3rd/7th固定） |
| 3分 | 2コーラス目でブルース語彙を1つ追加 |

到達基準:
- ✅ 12小節フォームを迷わず通せる
- ⭐ 9-12小節で次周接続を安定化できる
- 🔥 12キーで同じターンアラウンド設計を維持できる
