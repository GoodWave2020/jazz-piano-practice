# 曲分析

ジャズスタンダードの分析ページを、曲ごとに蓄積するセクション。  
コード進行の暗譜ではなく、**機能・接続・実践運用**まで整理する。

---

## 使い方

1. まずこの一覧から曲を選ぶ
2. フォームとキーセンターを把握する
3. セクション単位の練習メニューを実施する
4. [即興フレーズ設計](/guides/improvisation-phrasing) と接続して1コーラス化する

## 追加時の共通フォーマット

新規曲を追加するときは、以下の見出し順で統一すると比較しやすい。

1. 曲の基本情報（Key / Form / Tempo / 参照データ）
2. フォームとキーセンター
3. セクション別コード機能
4. ガイドトーン接続（3rd/7th）
5. 即興設計（スケール/テンション）
6. コンピング設計
7. 練習メニュー（10〜20分）

ファイル命名例:
- `song-analyses/there-will-never-be-another-you.md`
- `song-analyses/all-the-things-you-are.md`
