# 12キー練習ガイド

「全12キーで練習する」を、実際に回せる形へ落とし込むための実践ページ。  
このガイドでは、**対象曲セット**、**向き合い方**、**週間ローテーション**を一体で整理する。

---

## 対象フェーズ

- 推奨開始: `Phase 2` 後半〜`Phase 4`
- 前提:
  - [練習ルール](/guides/practice-rules) を読んでいる
  - ii-V-I / ii-V-i の基本形を理解している
  - 1〜2曲をキー固定で通せる

---

## 12キー練習の目的

1. **初見対応力を上げる**
2. **苦手キーの偏りをなくす**
3. **進行語彙をどの曲にも移植できる状態にする**

「全曲を毎日12キー」は非現実的なので、**進行の塊を回す**のが基本方針。

## 向き合い方（実践ルール）

1. **進行単位で移調する**
曲全体より先に `ii-V-I`、`iiø-V-i`、`ブルース9-12小節` を全キー化する。
2. **強拍の着地音を固定する**
1拍目/3拍目を3rdか7thに固定し、弱拍で色を足す。
3. **速度より再現性を優先する**
テンポは「崩れない最速」。崩れたら`-10`。
4. **苦手キーを翌日に繰り越す**
その日の失敗キーを次日の最初に再実施する。
5. **録音は週1でよい**
週末に1コーラス通しを録音し、着地の精度だけ確認する。

---

## キー順の設計

推奨キー順（4度進行、フラット優先）:

`F -> Bb -> Eb -> Ab -> Db -> Gb -> B -> E -> A -> D -> G -> C`

キーを4つのブロックに分ける:

- Block A: `F, Bb, Eb`
- Block B: `Ab, Db, Gb`
- Block C: `B, E, A`
- Block D: `D, G, C`

---

## 週間ローテーション（30分/日）

### 4日で12キーを1周する型

| 曜日 | キーブロック | 曲セット | 重点 |
|------|-------------|----------|------|
| Day 1 | Block A | Tune Up / Autumn Leaves | メジャーii-V-I + マイナーii-V-i |
| Day 2 | Block B | Oleo / There Will Never Be Another You | Rhythm Changes + 終止連鎖 |
| Day 3 | Block C | Billie's Bounce / Blues For Alice | ブルース基礎 + Bird Blues |
| Day 4 | Block D | All The Things You Are / Stella By Starlight | 多キー移動 + 複合終止 |

### 5日目（任意）

- 苦手キーだけ再テスト
- `Bolivia` など拡張曲を1キーずつ追加

### 6日目（任意）

- 週次録音（各曲1コーラス）
- 次週の優先キーを決定

---

## 1日の30分テンプレ

| 時間 | 内容 |
|------|------|
| 5分 | 当日キー3つでウォームアップ（ii-V-I + iiø-V-i） |
| 10分 | 曲セット1曲目（キー3つ） |
| 10分 | 曲セット2曲目（キー3つ） |
| 5分 | 苦手キーを再実施 + メモ |

メモ項目（最小）:

- 失敗した小節
- 失敗したキー
- 明日の先頭でやる内容

---

## 4週間の進め方

### Week 1

- 強拍3rd/7th固定で回す（テンション禁止）

### Week 2

- V7のみテンション追加（9,13中心）

### Week 3

- リズム変化を追加（休符・シンコペーション）

### Week 4

- 2コーラス運用（1コーラス目: 骨格 / 2コーラス目: 拡張）

## 達成基準

| 基準 | 条件 |
|------|------|
| ✅ 最低ライン | コア6の主要進行を12キーで止まらず処理できる |
| ⭐ 実用レベル | 当日指定キーで1コーラスを安定して通せる |
| 🔥 自動化レベル | キー指定を受けて即座に語彙を移植できる |
