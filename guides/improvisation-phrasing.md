# 即興フレーズ設計ガイド

「スケールは覚えたのにジャズっぽくならない」を解消するための実践ガイド。  
アルペジオ、テンション、スケール、リックをどう組み合わせて1つのフレーズにするかを、設計手順として整理する。

---

## 対象フェーズ

- 推奨開始: `Phase 2` 後半〜`Phase 3`
- 前提:
  - ii-V-I / ii-V-i を主要キーで弾ける
  - コードトーン（1-3-5-7）で最低1コーラスのソロが取れる
  - [コード進行パターン](/guides/chord-progressions) を一通り読んでいる

---

## なぜ「スケールだけ」だとジャズっぽくならないのか

スケールは「使える音の集合」であって、フレーズそのものではない。  
ジャズらしさは、音の並びより先に「どの拍で何に着地するか」で決まる。

| 要素 | 役割 | これだけだと起きる問題 |
|------|------|------------------------|
| アルペジオ | 和声の骨格（着地点） | 線が単調になりやすい |
| スケール | 骨格をつなぐ経過音 | 上下運動だけになりやすい |
| テンション | 色彩と緊張 | 文脈なしだと濁って聴こえる |
| リック | 言語の定型句 | そのまま貼ると借り物感が出る |

結論として、**骨格（アルペジオ）→ 接続（スケール）→ 色彩（テンション）→ 文法（リック）** の順で扱うと機能しやすい。

---

## 即興の優先順位（実戦用）

1. **リズムを先に決める**  
   音高より先に、休符とアクセントを決める。
2. **強拍の着地音を決める**  
   各コードで `3rd` か `7th` を優先。
3. **着地音同士をつなぐ**  
   スケール音またはクロマチックで接続。
4. **テンションで色を足す**  
   まず `9th`、次に `13th`、最後にオルタード。
5. **リックを挿入して言語化する**  
   丸コピーではなく、着地音を変えて再配置する。

---

## テンション運用の実践ルール（最優先）

最初は以下のルールを固定すると、テンションが「濁り」ではなく「解決を作る音」として機能する。

1. **強拍はコードトーン、弱拍でテンション**  
   まずは `1拍目/3拍目` を `1-3-5-7` に固定し、`裏拍` にテンションを置く。
2. **テンションは解決の前後で使う**  
   解決直前で緊張を作り、次コードのコードトーンで回収する。
3. **V7 のテンションは解決音を先に決める**  
   例: `G7(b9)` の `Ab` は `CMaj7` の `G` か `E` に向ける。
4. **長く伸ばすテンションは限定する**  
   まずは `Maj7` の `9 / 13`、`m7` の `9 / 11` から。
5. **1フレーズ1種類から開始する**  
   1つの2小節フレーズにテンションを詰め込みすぎない。

### 強拍/弱拍の運用早見表

| 場面 | まず置く音 | テンションの置き方 |
|------|-----------|------------------|
| 強拍（1拍目/3拍目） | 3rd or 7th | 基本は置かない（慣れてから解禁） |
| 弱拍（裏拍） | 経過音 | 9th/13th を優先して配置 |
| V7の終端 | 3rd or b7 | b9/#9/#11/b13 で緊張を作り次コードへ解決 |
| Iへの解決直後 | 3rd or 6th | 9th を短く添えて安定させる |

---

## テンション多めスケールの使い分け

「テンションが多いスケール」は便利だが、**いつ使うか**を決めないとただ濁る。  
基本は「V7で使ってIで解決」を軸にする。

| スケール | 主なテンション | 主な適用先 | 効く場面 |
|---------|---------------|-----------|---------|
| オルタード | b9, #9, #11, b13 | V7（特にマイナー解決） | 解決前の最大緊張 |
| コンディミ（H-W） | b9, #9, #11, 13 | V7 | ドミナントを長く引っ張る時 |
| ホールトーン | 9, #11, b13 | 7(#5)系V7 | 浮遊感のあるドミナント |
| リディアンb7 | 9, #11, 13 | 裏コード/バックドア/サブV | 明るめで洗練された響き |
| メロディックマイナー（m上） | 9, 11, 13 | mMaj系、サブドミナントマイナー文脈 | 暗さと透明感の両立 |

### 使う順番（安全）

1. ミクソリディアン（基準）  
2. V7 だけオルタード  
3. 同じV7でコンディミに差し替えて比較  
4. 裏コードでリディアンb7を導入

### 2小節練習ルール

1. `ii-V-I` を2小節でループする  
2. `ii` と `I` は固定（ドリアン/イオニアン）  
3. `V` のスケールだけ毎周差し替える  
4. 強拍着地が崩れたら即テンポを下げる

---

## 2小節テンプレ（ii-V-I）

まず「2小節を1文」として設計する。

### Step 1: 骨格だけ作る（アルペジオ）

- Dm7 で `F(3rd)` 着地
- G7 で `B(3rd)` 着地
- CMaj7 で `E(3rd)` 着地

### Step 2: つなぎを入れる（スケール）

- Dドリアン / Gミクソリディアン / Cイオニアンで接続
- ただし強拍の着地は Step 1 の音を維持

### Step 3: 色を足す（テンション）

- Dm7: `9th(E)`
- G7: `13th(E)` または `b9(Ab)`
- CMaj7: `9th(D)`

### Step 4: 語彙にする（リック化）

- 同じリズムで着地音だけ差し替え、別キーへ移調
- 4キー回せたら「語彙化できた」と判断

---

## 各素材との向き合い方

### 1. アルペジオ

- 目的: コードチェンジを可視化する
- 練習: 1小節1コードで `1-3-5-7`、次に `3-5-7-9`
- 判定: 強拍がコードトーンなら合格

### 2. スケール

- 目的: 着地音間の移動を滑らかにする
- 練習: 「上行/下行」ではなく「次の着地音へ最短で向かう」
- 判定: スケールを弾いてもコード感が消えない

### 3. テンション

- 目的: サウンドのキャラクターを作る
- 練習順:
  1. 9th だけ
  2. 13th と #11 を追加
  3. V7 のみオルタード化
- 判定: 解決先で緊張がほどけて聴こえる

### 4. リック

- 目的: 即興時の発話速度を上げる
- 練習: 2小節リックを「開始拍」「着地音」「終止音」で分解
- 判定: 別曲・別キーでも意味を保って使える

## ありがちな失敗と修正

| 失敗 | 原因 | 修正 |
|------|------|------|
| スケール練習っぽい音になる | 強拍着地が未設計 | 3rd/7th着地を先に固定 |
| テンションが濁る | 解決先を見ていない | V7で使ったテンションの解決音を決める |
| リックが浮く | 文脈と拍が不一致 | 2小節境界で挿入し、終止位置を合わせる |
| 音が多くて歌えない | リズム設計不足 | 2拍以上の休符を意図的に入れる |

## 20分ルーティン（毎日）

| 時間 | 内容 |
|------|------|
| 4分 | アルペジオ着地（ii-V-I を4キー） |
| 4分 | 着地固定でスケール接続（経過音のみ変更） |
| 4分 | テンション運用 + V7スケール差し替え（ミクソ→オルタード→コンディミ） |
| 4分 | 2小節リックを1つ移調（最低4キー） |
| 4分 | 曲に適用（Autumn Leaves / Blue Bossa / Now's the Time） |

ルール:
- テンポは `崩れない最速` で固定
- 崩れたら `-10` して再実施
- 録音して「強拍着地が見えるか」を確認

---

## 曲へ落とし込む順番

1. **Autumn Leaves**  
   ii-V-I と ii-V-i の往復で、素材統合を練習しやすい。
2. **Blue Bossa**  
   16小節で短く、同じ素材を反復しやすい。
3. **Now's the Time / Billie's Bounce**  
   ブルース上で「語彙の反復と変形」を練習できる。
4. **Oleo**  
   ターンアラウンドでリック運用の精度が問われる。

## 到達基準

| 基準 | 条件 |
|------|------|
| ✅ 最低ライン | 2小節フレーズを「骨格→接続→色彩」の順で説明しながら弾ける |
| ⭐ 実用レベル | 1曲で2コーラス、アルペジオ/テンション/リックを混ぜても破綻しない |
| 🔥 自動化レベル | 別曲でも同じ設計手順で即興を再現できる |
