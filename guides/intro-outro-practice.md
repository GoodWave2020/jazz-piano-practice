# イントロ/アウトロ練習ガイド

ピアニストの本番力は、テーマやソロだけでなく**入り方と終わり方**で大きく差が出る。
このページでは、セッションやライブで使えるイントロ/アウトロの考え方と、練習手順を整理する。

---

## 対象フェーズ

- 推奨開始: `Phase 2` 後半〜`Phase 4`
- 前提:
  - [ボイシングパターン](/guides/voicing-patterns) のシェル/ルートレスを使える
  - [コード進行パターン](/guides/chord-progressions) の ii-V-I とターンアラウンドを理解している
  - [セッション/ライブ心得](/guides/session-live-mindset) を読んでいる

---

## 基本方針

1. **イントロは「曲の入口を明確にする」** — テンポ・キー・雰囲気を伝える
2. **アウトロは「終止を合意させる」** — 聴衆が最後に聴くものが印象を決める
3. **難しい語彙より、合図とフォームを優先する**

本番で最優先すべきは、技巧よりも「全員が同じ場所に入る/終わる」こと。

---

## イントロの考え方

### まず決める3要素

1. 長さ（`2/4/8小節`）
2. テンポ導入方法（`rubato -> in tempo` か `最初からin tempo`）
3. テーマ頭への接続点（`頭打ち` か `アウフタクト`）

---

## イントロ・パターン集

### ボーカル/ホーンの頭出しキュー（ベルノート）

歌伴やフロント付き編成では、**「正しい入り音を短く提示する」**だけで事故率が大きく下がる。

- ベルノート: テーマ冒頭音を単音で提示して、1拍〜2拍の空白を作ってから本イントロへ入る
- ブロークンドミナント: V7（またはV+）を分散で鳴らして、テンポとキーを同時に提示する
- 迷った日は「ベルノート -> 最後4小節タグ」で固定すると、初共演でも入りやすい

### 1. 最後の4〜8小節タグ（最も安全）

曲の最後4〜8小節のコード進行をヴァンプしてからテーマに入る。ジャズスタンダードは循環的に作曲されているため、末尾から頭へ自然に接続する。

**利点：** 曲固有の進行をそのまま使うので、テーマ頭への接続が最も自然。
**使い方：** リードシートの最後の4小節のコードをそのまま演奏する。

### 2. I-VI-ii-V ターンアラウンド・ヴァンプ

曲のキーで `I-VI-ii-V` を4小節で繰り返す。Iコードで始まる曲ならほぼ全てに使える汎用パターン。

<AbcNotation abc='
X:1
T:I-VI-ii-V Turnaround Intro (C)
M:4/4
L:1/2
K:C
"Cmaj7"[EGBd] "Am7"[Aceg] | "Dm7"[FAce] "G7"[GBdf] |
"Cmaj7"[EGBd] "Am7"[Aceg] | "Dm7"[FAce] "G7"[GBdf] |
' />

- `iii-VI-ii-V`（`Em7-Am7-Dm7-G7`）も同様に機能する
- 最後の小節で音数を減らし、テーマ頭に空間を作る
- 事前に調性感を提示できるので、テーマ頭の和声が安定する
- 曲間つなぎにも有効。`I-VI-ii-V` を回しながら次曲メロ断片を引用し、最後のVで新曲頭に入る

### 3. ii-V-I 4小節イントロ

<AbcNotation abc='
X:1
T:4-Bar ii-V-I Intro (C)
M:4/4
L:1/2
K:C
"Dm7"[FAce] "G7"[GBdf] | "Em7"[EGBd] "A7"[A^ceg] |
"Dm7"[FAce] "G7"[GBdf] | "Cmaj7"[EGBd]2 |
' />

- 3小節目までii-Vの連鎖で緊張を作り、4小節目でIに解決してテーマへ
- ベース参加時は左手ルートを控え、3rd/7th中心にする

### 4. V7ペダル（ドミナント・ペダル）

V7のボイシングを左手ベース固定のまま、右手のテンションを様々に変化させて緊張を高め、Iに解決してテーマへ入る。

<AbcNotation abc='
X:1
T:Dominant Pedal Intro (C)
M:4/4
L:1/2
K:C
"G pedal"[G,DB][G,DF] | [G,DB][G,D^F] |
"G13(b9)"[G,BF][G,_AE] | "Cmaj7"[C,EGBd]2 |
' />

**ボイシングの要点：**
- 左手：Gペダル固定
- 右手：G7シェルの上に `Eメジャートライアド`（= G13(b9)のアッパーストラクチャー）
- b9やb13を使うとダークで緊張感のある響き
- バラード向き：「The Way You Look Tonight」「Over the Rainbow」「Misty」に最適

### 5. ルバート（自由テンポ）

バラードで特に有効。テーマの最初4〜8小節をテンポフリーで演奏し、途中からインテンポに移行。

- メロディを装飾したり、即興的なカデンツァを挿入できる
- テンポの揺れ・ルバートのセンスが直接サウンドに出る
- 終わりに4拍のカウントインを入れてインテンポへ接続

### 6. モーダル・ヴァンプ

曲の重要なコードを1つ選び、そのサウンドでヴァンプする。

- 例：最初のコードが `Fm7` なら、`C7alt` / `C7sus4` をヴァンプ → エネルギーが溜まったら `Fm7` に解決してテーマへ
- V7 → I の解決感を利用。V7sus4 → V7alt → I と徐々にテンションを上げるのも効果的
- モーダルな曲や、浮遊感を出したい時に

### 7. ラテン/ボサノバ用イントロ

I-VI-ii-V と同じ構造だが、ダイアトニックコードの代わりにドミナント7th変形を使う。

- 実戦では `Imaj7 -> VI7 -> II7 -> V7`（またはsus/altを含む）にすることが多い
- セカンダリードミナントの連鎖（E7, A7, D7 など）でクロマチックな動き
- 左手に `sus4` 装飾を入れ、3拍目で解決するクロマチックなパッシングトーンを作る
- ストレートエイス。「Girl from Ipanema」などのボサノバに

### 8. リフベース

テーマから特徴的なメロディ/リズム断片を取り出して繰り返す。

- 短く、キャッチーで、リズミックなものが効果的
- 自作のリフでもOK。曲の雰囲気に合うものを
- ループさせながら楽器を1つずつレイヤーイン（ドラム→ベース→ピアノ→ホーン）すると効果的

### 9. 即興1コーラスから開始

テーマの前に、コード進行上で1コーラス（または半コーラス）のソロを取ってからテーマに入る。いつもテーマから始まるパターンに変化を加えたい時に。

### 10. 作曲済みイントロ

一部の曲には伝統的に定番のイントロが存在し、そのまま演奏するのが慣例。

| 曲名 | イントロの特徴 |
|------|--------------|
| Body and Soul | 有名な作曲済みイントロ |
| Stardust | Verse部分がイントロとして使われる |
| Misty | ルバートのイントロが定番 |

### 11. Red Garland風クロマチック・ダウン（半音下降）

ハードバップ系でよく効く、**トップノートを半音ずつ下げるタグ**。  
イントロにもアウトロにも転用できる。

<AbcNotation abc='
X:1
T:Red Garland Chromatic Walkdown (F)
M:4/4
L:1/2
K:F
"Gm9" d "C7" c |
"Cm9" c "Bm9" B |
"Bbm9" _B "Am9" A |
"Abm9" _A "Gm9" G |
"F#m9" _G "Fmaj9" F2 |
' />

- 画像の型に合わせると、`Gm9 -> C7` の後に `Cm9 -> Bm9 -> Bbm9 -> Am9 -> Abm9 -> Gm9 -> F#m9 -> Fmaj9`
- `Gm9 -> C7` は導入。主要な半音下降は `Cm9` 以降のトップノート `C-B-Bb-A-Ab-G-Gb-F`
- 終止は `Fmaj9` でも `F6/9` でもよい（メロディがFなら `F6/9` が安全）
- 短縮版にするなら、`Bbm9 -> Am9 -> Abm9 -> Gm9 -> F#m9 -> Fmaj9` の3組だけ抜き出しても使える

**Red Garlandらしい弾き方（運用）**
- 左手: 4音のルートレス（Type A/B）を軽めに置く
- 右手: メロディをオクターブで取り、間に `m3` か `P4` を入れる
- リズム: 拍頭だけでなく `and of 2 / and of 4` の先取りで置くと、Garlandらしい推進力が出る
- 途中で理論上の衝突音が出ても、短く通過させれば色として機能する（いわゆる *Red Garland rub*）
- このm9連鎖は機能和声の厳密分析より、**半音ラインを保った平行移動の効果音**として扱う

## イントロ選択の目安

| 状況 | 推奨イントロ | 理由 |
|------|------------|------|
| 初共演 / 不安な日 | 最後4小節タグ or ii-V-I 4小節 | 安全、失敗しにくい |
| バラード | ルバート or V7ペダル | 雰囲気作りに時間をかけられる |
| ボサノバ / ラテン | ラテン用ストック or モーダルヴァンプ | Feel の提示が重要 |
| アップテンポ | I-VI-ii-V ターンアラウンド | シンプルで拍を明確に |
| モーダル曲 | モーダルヴァンプ or ペダルポイント | 機能和声の進行は合わない |
| ハードバップ / ピアノトリオ | Red Garland半音下降タグ | ブロックコードで推進力と色気を出せる |
| マンネリ打破 | リフベース or 即興1コーラス | サプライズと変化 |

## アウトロの考え方

### まず決める2要素

1. どこで終わるか（`最終A`、`テーマ終端`、`ソロ終端`）
2. 合図方法（`視線`、`キメ`、`タグ回数`）

## エンディング・パターン集

### 1. ♭IImaj7(#11) → Imaj7 エンディング（汎用性最高）

最終コードの直前に、**トニックの半音上のmaj7(#11)** を挿入してからIに解決する。ジャズで最も多用されるエンディング手法。

<AbcNotation abc='
X:1
T:bII-I Ending (Eb)
M:4/4
L:1
K:Eb
"Emaj7(#11)"[E^G_Bd] | "Ebmaj7"[_EG_Bd] |
' />

**なぜ機能するか：**
- Iのルート = ♭IIのmaj7th（共通音）
- ♭IIの#11 = Iの5th（共通音）
- ♭IIの3rd = V7の7th（トライトーンサブの関係）
- ♭IIの3rd → Iの3rd へ半音で美しく解決

**実戦のコツ：**
- メロディがルートで終わる場合、`I6/9` に解決するとmaj7とのぶつかり（短9度）を避けられる
- 曲例：「You Stepped Out of a Dream」のエンディング

**拡張版（五度圏の反時計回り）：**
- `♭VImaj7 → ♭IImaj7 → Imaj7`
- `♭IIImaj7 → ♭IImaj7 → Imaj7`
- 隣接コードが共通音を持つため、スムーズなヴォイスリーディングになる

### 2. Imaj7(#11) フェルマータ（迷ったらこれ）

最終トニックで `Imaj7(#11)` をフェルマータで伸ばす。最もシンプルで安全。

<AbcNotation abc='
X:1
T:Imaj7(#11) Fermata Ending (C)
M:4/4
L:1
K:C
"Cmaj7(#11)"[EG^Bd] |
' />

**注意：** メロディがルートで終わる場合、maj7（B）とルート（C）で短9度がぶつかる。メロディ音をmaj7, 9th, #11thのいずれかに変えるか、`I6/9` を使う。

- 曲例：「All The Things You Are」のエンディング

### 3. V7(alt.) カデンツァ・エンディング（バラード向き）

バンド全員で最後のV7alt（最低限b9を含む）で止まり、ソリスト（またはピアニスト）が即興カデンツァを演奏。終わったらキューを出してImaj7で全員がカットオフ。

<AbcNotation abc='
X:1
T:V7alt Cadenza Ending (Bb)
M:4/4
L:1
K:Bb
"F7(b9)"[F,_A_eG]- [F,_A_eG] | "Bbmaj7"[_B,DFA]2 |
' />

- バラードの「Stella by Starlight」で定番
- カデンツァの長さは演奏者の判断。短い方が洗練された印象

### 4. I7(#9) エンディング（ブルージー終止）

最後のトニックを `I7(#9)` で保持する。ブルージーで荒い響き。

<AbcNotation abc='
X:1
T:I7(#9) Ending (Bb)
M:4/4
L:1
K:Bb
"Bb7(#9)"[_B,DA^c] |
' />

- ブルースや Rhythm Changes に特に合う
- メロディの最後の音を#9に変えると効果的
- 明るく解決しすぎず、少しラフな余韻を残したい時に有効

### 5. "Take the A Train" エンディング

バンド全員でユニゾンの決めフレーズを演奏する古典的エンディング。メロディがトニックのルートで終わる曲に最適。

- やや「定番すぎる」印象もあるが、必修パターン
- コードの有無（最後にホールドするかしないか）は事前に合意

### 6. iv7 → ♭VII7 → Imaj7（バックドア・エンディング）

[バックドア進行](/guides/chord-progressions)をエンディングに転用。柔らかい解決感が特徴。

<AbcNotation abc='
X:1
T:Backdoor Ending (C)
M:4/4
L:1/2
K:C
"Fm7"[F_A_Bc] "Bb7"[_BDFa] | "Cmaj7"[CEGBd]2 |
' />

- 「Just Friends」「Misty」で実際に曲中に使われている進行をエンディングに応用
- ♭IIIキーからのii-V進行のような動き

**拡張版（クロマチック上行ルート）：**
- `♭VII7 → VII13(b9) → Imaj7`
- E♭キーなら `D♭13 → D13(b9) → E♭maj7`
- 半音上行のベース移動がドラマチック

### 7. タグ・エンディング（ii-V-I反復）

最終トニックをii-V-Iに拡張して2〜4回反復し、最後に解決。

<AbcNotation abc='
X:1
T:Tag Ending (C)
M:4/4
L:1/2
K:C
"Dm7"[FAce] "G7"[GBdf] | "Cmaj7"[EGBd] "A7"[A^ceg] |
"Dm7"[FAce] "G7"[GBdf] | "C6/9"[EGAd]2 |
' />

- タグ回数は事前に合意（通常2〜3回）
- 最後のタグに入る前に視線で合図
- 最終小節で `C6/9` に着地するとmaj7のぶつかりを避けられる

### 8. ヴァンプ＆フェードアウト

最終トニックからI-VI-ii-Vを2拍ずつでループし、即興しながらフェードアウト。

**ヴァンプに使えるコード：**

| コード | 響きの特徴 | 合う場面 |
|--------|----------|---------|
| `I7(sus4)` | 開放的 | ファンキーな曲 |
| `V7(sus4)` | 浮遊感 | モーダルな曲 |
| `Im7` | ダーク | マイナーモーダル |
| `♭IImaj7(#11)` | リッチ | 余韻を残したい時 |

- メロディの最後のモチーフをリフとして使い、変化させながら繰り返すのが効果的

### 9. リタルダンド・エンディング

最後の数小節で徐々にテンポを落とし、最終コードをフェルマータ。

- rit.は急激に落とさず、2小節で段階的に減速
- バラードやミディアムテンポに自然にフィット
- シンプルだが、バンド全員のテンポ感覚が揃っている必要がある

### 10. Barry Harris式クロマチック連鎖（上級）

`ii → V → ♭IIImaj7 → ♭VImaj7 → ♭IImaj7 → Imaj7`

B♭キーの例：`Cm7 → F7 → D♭maj7 → G♭maj7 → Bmaj7 → B♭maj7`

- 全ての代理コードに**同じメロディ音が含まれる**のがポイント
- 五度圏の反時計回りに隣接するmaj7を連鎖させる
- 非常に洗練された響きだが、暗記と練習が必要

### 11. 最終アルペジオ（着地の見栄えを揃える）

最終コードを保持した直後に、**トニックの5度上メジャートライアド**を上行アルペジオで置く。短い動きで「終わった感」を作れる。

<AbcNotation abc='
X:1
T:Final Arpeggio Over Imaj13 (C)
M:4/4
L:1/4
K:C
"Cmaj13" G B d g |
' />

- Cメジャーなら `G-B-D`（= Cの5th, 7th, 9th）を使う
- `Imaj7 / Imaj9 / Imaj13` の終止で共通して使える
- メロディがルート着地の場合は、先に `I6/9` で保持してからアルペジオに移ると濁りにくい

## メジャー / マイナー別の最終コード

| 曲のキー | 推奨最終コード | スケール素材 | 注意 |
|---|---|---|---|
| メジャー | `Imaj7`, `I6/9`, `Imaj7(#11)` | リディアンスケール | メロディがルートの場合は `I6/9` が安全 |
| マイナー（機能和声） | `Im6`, `Im(maj7)` | メロディックマイナー | 終止感を強めたい時に有効 |
| マイナー（モーダル） | `Im7`, `Im9` | ドリアン / エオリアン | 浮遊感重視。トニック感は弱めになりやすい |

**リディアンの使い方：** 最終コードの上にリディアンスケール（#4を含むメジャースケール）の音を積む。ルート+5thを低音で確立し、その上に3rd, maj7, 9th, #11, 13thを重ねる。

**マイナーの「フィルムノワール」サウンド：** `Im6`（1-♭3-5-6）または `Im(maj7)`（1-♭3-5-7）でメロディックマイナーの響きを出す。クラシカルで陰影のあるエンディングに。

## エンディング選択の目安

| 状況 | 推奨エンディング | 理由 |
|------|----------------|------|
| 迷ったとき | `Imaj7(#11)` フェルマータ | 最もシンプルで安全 |
| 洗練した響きが欲しい | `♭IImaj7(#11) → Imaj7` | 汎用性最高。必修 |
| バラード | `V7(alt.)` カデンツァ | 余韻とドラマ |
| ブルース / Rhythm Changes | `I7(#9)` | ブルージーで力強い |
| 柔らかい着地 | バックドア `iv7-♭VII7-I` | 穏やかな解決 |
| ハードバップで締めたい | Red Garland半音下降 + `I6/9` | クロマチックな着地が映える |
| 初共演 / 不安な日 | タグ2回 + フェルマータ | 回数さえ合意すれば確実 |
| ファンキーな曲 | ヴァンプ＆フェードアウト | グルーヴを維持したまま終了 |

## 練習方法（段階別）

### Step 1: 形の固定

- イントロ3種類、エンディング3種類を選ぶ
  - **イントロ：** 最後4小節タグ / I-VI-ii-V / V7ペダル
  - **エンディング：** ♭IImaj7→I / Imaj7(#11) / タグ2回
- まずC, F, B♭, E♭の4キーで固定

### Step 2: 接続練習

- `イントロ -> テーマ8小節` を連続で反復
- `テーマ終端 -> エンディング` を連続で反復
- 本文ではなく「接続の瞬間」だけ切り出して練習

### Step 3: 合図練習

- 視線を送るタイミングを固定する
- 「あと1回タグ」の合図を声に出して確認する
- ドラム/ベースと終止長を合わせる

### Step 4: 12キー化

- 4度進行で3キーずつ回す
- 苦手キーは翌日の最初に再実施

### Step 5: スタイル別の拡張

- バラード用：ルバート + V7カデンツァ終止
- ラテン用：ラテンイントロ + ヴァンプ終止
- ブルース用：ターンアラウンド + I7(#9)終止
- ハードバップ用：Red Garland半音下降タグ + `I6/9` 着地

---

## 20分ルーティン

| 時間 | 内容 |
|------|------|
| 5分 | イントロ3種（当日キー3つ） |
| 5分 | エンディング3種（当日キー3つ） |
| 5分 | `イントロ -> テーマ頭` 接続練習 |
| 5分 | `テーマ終端 -> エンディング` 接続練習 |

ルール:
- 失敗したら曲全体に戻らず、接続2小節だけやり直す
- 1日で新規パターンを増やしすぎない（最大1つ）

---

## 現場での運用ルール

1. コール時にイントロ長を必ず宣言する（「4小節で入ります」）
2. タグ回数を曖昧にしない（「タグ2回」「3回目で終わり」）
3. 不安な日は「4小節ii-V-I + タグ2回」に固定する
4. 初共演メンバーには複雑なエンディングを避ける
5. **ストック・イントロ/エンディングを最低3つずつ暗記しておく**（スイング/バラード/ラテン各1つ）
6. **最後の印象が最も重要** — エンディングは聴衆が最後に聴くもの。必ず綺麗に終わる

---

## よくある失敗

| 失敗 | 原因 | 修正 |
|------|------|------|
| 入りがずれる | イントロ終端の空間不足 | 最後1小節で音数を減らす |
| 終わりが揃わない | タグ回数未共有 | 事前に回数固定 + 視線合図 |
| rit.でテンポ崩壊 | 減速幅が急すぎる | 2小節で段階的に落とす |
| 低音が濁る | ベースとルート衝突 | 右手中心のルートレスへ変更 |
| メロディとコードがぶつかる | 最終コードの選択ミス | メロディがルート→I6/9、メロディがmaj7→Imaj7 |
| ♭IIエンディングで不協和 | ♭IIの構成音を間違えている | ♭IImaj7(#11)を全12キーで暗記する |

## 到達基準

| 基準 | 条件 |
|------|------|
| ✅ 最低ライン | イントロ3種/エンディング3種を4キーで再現できる |
| ⭐ 実用レベル | 本番でコールどおりに入り/終わりを安定運用。♭IImaj7エンディングを全キーで使える |
| 🔥 自動化レベル | 曲調と編成に応じてその場で最適な型を選択。Barry Harris式連鎖も使いこなせる |
