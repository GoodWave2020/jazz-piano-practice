# 推奨リソース

## 書籍・教材

| リソース | 用途 | 優先度 |
|---------|------|--------|
| **The Jazz Piano Book**（Mark Levine） | ジャズピアノの教科書。ボイシング〜アドリブまで網羅 | ★★★ |
| **The Real Book** | スタンダードのリードシート集。必携 | ★★★ |
| **ジャズハノン** | 鍵盤の基礎テクニック | ★★☆ |
| **The Virtuoso Pianist**（Hanon） | 指の独立性・スピード向上。クラシックの定番 | ★☆☆ |
| **Jazz for the Young Pianist**（Oscar Peterson） | ジャズ向けフィンガーエクササイズ | ★☆☆ |

## アプリ・ソフトウェア

| リソース | 用途 | 優先度 |
|---------|------|--------|
| **iReal Pro**（アプリ、有料） | マイナスワン音源。全フェーズで必須 | ★★★ |
| **Transcribe!**（ソフト） | 耳コピ支援（テンポ変更・ループ・ピッチ変更） | ★★☆ |
| **Functional Ear Trainer**（アプリ、無料） | イヤートレーニング。スケールディグリーの聴き取り | ★★☆ |

## Webサイト

| リソース | 用途 | 優先度 |
|---------|------|--------|
| **[The Jazz Piano Site](https://www.thejazzpianosite.com/jazz-piano-lessons/)** | 無料の体系的ジャズピアノレッスン。初心者〜上級者まで。基礎理論、スケール、ボイシング、即興、リハーモナイゼーション、モダンジャズまで全カバー。練習ルーティンの動画解説もあり | ★★★ |
| **[Learn Jazz Standards](https://www.learnjazzstandards.com/blog/)** | スタンダードの学び方、コンピング、リハーモナイゼーション、理論の記事が充実 | ★★☆ |
| **[JazzAdvice](https://www.jazzadvice.com/)** | トランスクリプション、ジャズランゲージ、イヤートレーニング等のコース | ★★☆ |
