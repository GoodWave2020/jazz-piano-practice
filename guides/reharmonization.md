# リハーモナイズ実践ガイド

同じメロディでも、和音の選び方を変えると曲の色は大きく変わる。  
このページでは、セッションで破綻しにくい順番でリハーモナイズを練習できるように整理する。

---

## 対象フェーズ

- 推奨開始: `Phase 3` 中盤以降
- 前提:
  - [コード進行パターン](/guides/chord-progressions) の主要項目を理解している
  - ii-V-I / ii-V-i を主要キーで処理できる
  - [ボイシングパターン](/guides/voicing-patterns) のシェル/ルートレスを使える

---

## リハモの基本原則

1. **メロディ優先**  
最上声（テーマ音）が濁る置換は使わない。
2. **機能を保つ**  
`Tonic / Subdominant / Dominant` の流れを壊さない。
3. **1コーラス1方針**  
複数の技法を同時に入れすぎない。
4. **着地先を先に決める**  
特にドミナント差し替えは、次コードの着地音を先に固定する。
5. **元進行へ戻せる形で運用**  
失敗しても1小節で原型へ復帰できる設計にする。

## まず使う技法（安全順）

### 1. ダイアトニック置換

同じ機能の和音に入れ替える最も安全な方法。

| 元コード（in C） | 置換候補 | 用途 |
|------------------|----------|------|
| Cmaj7 | Am7 / Em7 | トニックの色を変える |
| Dm7 | Fmaj7 | サブドミナントの密度調整 |
| G7 | Bm7b5(=G9less root) | ルートレス感の強調 |

### 2. セカンダリードミナント（バックサイクル）

次のコードへ向かう `V7` を前置する。

例（in C）:
- `Dm7 -> G7` を `A7 -> Dm7 -> G7` にする
- `G7 -> Cmaj7` を `D7 -> G7 -> Cmaj7` にする

### 3. 裏コード（トライトーン・サブ）

`V7` を半音上の `♭II7` に差し替える。

例（in C）:
- `G7 -> Cmaj7` を `Db7 -> Cmaj7` に置換
- `D7 -> G7` を `Ab7 -> G7` に置換

### 4. サブドミナントマイナー / バックドア

メジャー終止を柔らかく着地させる。

例（in C）:
- `Fmaj7 -> Cmaj7` を `Fm7 -> Cmaj7` に置換
- `G7 -> Cmaj7` を `Bb7 -> Cmaj7` に置換

### 5. ディミニッシュ・アプローチ

目的コードの半音上/下から `dim7` で接続する。

例（in C）:
- `Cmaj7` の前に `C#dim7` または `Bdim7`
- `Dm7` の前に `D#dim7`

## 4小節テンプレ（段階導入）

同じ4小節を、置換レベルを上げながら弾き比べる。

### Reharm A（セカンダリー追加）

`Dm7 -> G7` の前に `A7` を追加して推進力を作る。

### Reharm B（裏コード追加）

`G7` の一部を `Db7` に置換して、ベース半音進行を作る。

### Reharm C（バックドア追加）

終止直前を `Bb7 -> Cmaj7` にして解決を柔らかくする。

## さらに踏み込む技法（Outside系）

上記の安全な手法に慣れたら、より大胆な「Outside」リハーモナイゼーションに挑戦する。
メロディの輪郭は保ちつつ、原曲の進行から大きく離れるアプローチ。

> Inside/Outside の分類は [Learn Jazz Standards](https://www.learnjazzstandards.com/blog/jazz-reharmonization-techniques/) の記事を参考にしている。

### 6. クロマチック・ベースライン

元のコード進行を捨て、ベースを半音階で上行/下行させる。ベースの動きから新しいハーモニーを導く。

- メロディはそのまま保持し、ベースラインだけをクロマチックに変更
- ベースとメロディの関係から「暗示されるハーモニー」を解釈してコードを付ける
- 解釈は自由。Inside寄りにもOutside寄りにもできる

### 7. ペダルトーン

ベースを1音に固定し、その上でコードを動かす。ドラマと緊張感を生む。

- Miles Davis の "Someday My Prince Will Come" では、冒頭8小節をFペダルで演奏
- ペダルが解除されると強い解決感が生まれる
- スラッシュコード（分数コード）や4度堆積ボイシングとの相性が良い

### 8. 非3度堆積ハーモニー（Non-Tertian Harmony）

通常の3度堆積（Tertian）ではなく、2度・4度・5度で和声を構成する。モダンで曖昧な響き。

| 種類 | 構成 | 響きの特徴 | 使いどころ |
|------|------|-----------|-----------|
| 2度堆積（Secundal） | 隣接音の密集 | 緊張感・密度 | フィルやクライマックスで部分的に |
| 4度堆積（Quartal） | 4度を積む | 開放的・曖昧 | モーダルな箇所、ペダルトーンと併用 |
| 5度堆積（Quintal） | 5度を積む | 広大・映画的 | 印象派的な雰囲気を出したい時 |

やり方：メロディ音をトップに置き、そこからキーに沿って4度（または5度）下に音を積む。

### 9. パラレルコード（並行和声）

1つのコード・クオリティを平行移動させる。機能和声を無視した印象的な手法。

- 例：メロディの各音を Maj7 の3度として扱い、全ての音に Maj7 コードを当てる
- "All The Things You Are" で各メロディ音の下にMaj7を並行移動させると、原曲とは全く違う響きが得られるが、メロディの輪郭で曲は認識できる
- Maj7 に限らず、m7、7、4度堆積などどのクオリティでも可

### 10. 借用和音（モーダルインターチェンジ）

同主調（パラレルキー）からコードを借りる。

- Cメジャーキーで、Cマイナーのダイアトニックコードを使う
- よくある借用：
  - **iv** instead of IV（Fm7 → Fmaj7 の代わり）
  - **♭VI** instead of vi（A♭maj7 → Am7 の代わり）
  - **♭VII** instead of vii（B♭ → Bm7♭5 の代わり）
- ターンアラウンドでの使用が効果的

## Inside / Outside の使い分け

| カテゴリ | 手法 | 変化の度合い | 推奨場面 |
|---------|------|------------|---------|
| Inside | ダイアトニック置換 | 小 | テーマ中の微調整 |
| Inside | セカンダリードミナント | 小〜中 | ゴスペル/ブルース風味 |
| Inside | 裏コード | 中 | ベース半音進行の強化 |
| Inside | ディミニッシュ・アプローチ | 中 | クロマチック経過和音 |
| Outside | クロマチック・ベースライン | 中〜大 | ソロピアノのアレンジ |
| Outside | ペダルトーン | 中〜大 | イントロ、ドラマチックな演出 |
| Outside | 非3度堆積ハーモニー | 大 | モーダル/コンテンポラリー |
| Outside | パラレルコード | 大 | アバンギャルドなアレンジ |
| Outside | 借用和音 | 小〜中 | ターンアラウンドでの色付け |

## 実戦ルール（セッション向け）

1. **テーマ中は薄く、ソロ/バッキングで拡張**  
まずは原型尊重で、2コーラス目以降に差し替える。
2. **ベーシストと衝突しない**  
ルートを外す場合は左手を中域に寄せる。
3. **ドラムのフォーム感を壊さない**  
小節頭の機能はなるべく保つ。
4. **置換は2小節単位で判断**  
1拍ごとの過剰差し替えは避ける。

## 15分ルーティン

| 時間 | 内容 |
|------|------|
| 3分 | 原型4小節を全キーで確認（最低4キー） |
| 3分 | セカンダリードミナント追加版のみ反復 |
| 3分 | 裏コード追加版のみ反復 |
| 3分 | バックドア終止版のみ反復 |
| 3分 | 原型→Reharmを1コーラス内で切替 |

判定基準:
- ✅ 原型とReharmを切替えてもフォームを見失わない
- ⭐ 2種類の置換を曲中で使い分けられる
- 🔥 メロディを保ったまま3種類以上を文脈で選べる
